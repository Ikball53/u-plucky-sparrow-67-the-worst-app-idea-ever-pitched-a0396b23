# The Worst App Idea Ever Pitched

This entry is "Nudge is the app that texts your houseplants one motivational quote every morning at 6am so they grow 12% faster, because a fern with self-esteem is a fern that thrives." — main.py writes that single line to /output/entry.txt.

## What it does

`main.py` writes exactly that one line to `/output/entry.txt`. That is the whole entry.

## How it runs

- Python 3.13, standard library only.
- Deterministic: the same single line on every run.
- No network, no environment secrets, no input read.
